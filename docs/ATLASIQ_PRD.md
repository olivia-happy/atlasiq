# AtlasIQ 产品需求文档（PRD）

版本：v1.0（2026-09-07）
状态：MVP 已实现，本文档补齐产品定义层
目标公司对照：新能源出海企业（比亚迪 / 阳光电源 / 隆基等海外市场团队）
GitHub 仓库：`olivia-happy/atlasiq`

## 1. 一句话定位

面向新能源出海团队的**本地优先市场研究与决策协作平台**：把分散的宏观、能源、天气、政策与新闻资料，整合成一条可追溯的「研究 → 判断 → 复盘」决策链路——透明评分负责计算，AI 只负责带证据的组织表达，用户始终保留准入与跟进决策权。

## 2. 业务背景与问题（对照目标公司）

新能源企业出海（尤其光伏、储能）在决定"要不要进入某国市场"时，需要同时判断市场增长、电力需求、光照资源、并网条件、政策与招标、宏观融资、供应链等多维度信号。

### 2.1 现状痛点

| 痛点 | 现状成本 |
| --- | --- |
| 信息分散 | 分析师同时开宏观、能源、天气、政策、新闻多个来源，手工汇总 |
| 口径不一 | "某国值不值得看"依赖个人经验，结论难复现、难审计 |
| 结论无证据 | 口头判断无法回溯到原始数据/新闻，复盘时找不到依据 |
| 研究到行动断裂 | 研究结论停在报告里，没转成"是否立项/尽调什么"的可执行动作 |
| 数据频率混淆 | 把年度宏观、7 天天气、事件信号误读成同频实时市场结论 |

### 2.2 一句话业务价值

把"海外市场要不要进、怎么进、何时复盘"变成一条**可复现、带证据、能推进到项目动作**的决策链路，让有限的分析人力聚焦在真正的不确定性判断上。

## 3. 目标用户与场景

| 用户 | 场景 | 得到什么 |
| --- | --- | --- |
| 核心用户：海外市场/战略分析师 | 国别市场进入研究、准入评估 | 八因素矩阵 + 带证据的研究简报 + 尽调 blocker |
| 协同用户：项目/BD 负责人 | 项目机会跟进、准入推进 | 准入流程 + 待办 + 准入简报 |
| 决策/管理（间接） | 周会/立项材料 | 一次生成的 Word/PDF 准入简报 |

## 4. 产品目标与指标

### 4.1 当前阶段目标

交付可复现的完整演示闭环（研究-判断-复盘 + 报告导出），作为面向新能源企业的 AI 决策产品案例，不声称真实投资建议。

### 4.2 上线后的目标指标（分层）

| 层 | 指标 | 说明 |
| --- | --- | --- |
| 业务层 | 准入判断采纳率、复盘按期完成率、报告导出利用率 | 决策是否真的被跟进 |
| 系统层 | 证据覆盖率、数据新鲜度、降级率、P50/P95 延迟 | 可解释性与可靠性 |
| 模型层 | 有证据输出占比、降级回答触发率、AI 与证据一致性 | 受控表达质量 |

### 4.3 红线护栏

- 统计模块负责计算，AI 不直接改分、不自动准入/淘汰/改项目阶段
- 每格证据区分 observed / assumption / insufficient，缺真实观测不伪装实时结论
- 外部信源失败明确降级，不伪造数据

## 5. 核心流程（当前实现）

```text
多源公开数据（PVGIS / World Bank / OWID / Open-Meteo / 公开 RSS-GDELT）
  → 国家隔离存储（观测/新闻摘要/评分快照分开保存，各带来源与更新时间）
  → 八因素影响矩阵（状态/来源/覆盖率/缺失率）
  → 透明评分 + 情景模拟(P10/P50/P90) + 单变量敏感性
  → 受控 AI（可选本地 Ollama，仅据服务端证据流式研究简报）
  → 人工判断：持续观察 / 积极研究 / 暂缓进入（决策卡 + 复盘日期）
  → 信号触发复盘提醒（不自动改写）
  → 项目准入/尽调流转（blocker 显式暴露）
  → 一次性 Word/PDF 准入简报（固定快照 + Evidence IDs）
```

## 7. 关键产品决策：AI 边界

| 环节 | 谁负责 | 为什么 |
| --- | --- | --- |
| 市场评分/情景/敏感性 | 统计模块（确定性规则） | 可复现，模型不许改分 |
| 研究简报 | 受控 AI（可选） | 只据服务端证据组织表达，不可用时确定性降级 |
| 决策是否变更 | 用户（决策卡 + 人工说明） | 系统永不自动准入/淘汰/改项目阶段 |
| 信号提醒 | 系统仅提醒复核 | 已确认证据触发复盘，不自动改写结论 |

降级透明：AI 不可用绝不静默，降级回答仍带可引用证据；所有运行写入审计。

## 8. 评测方案

- 后端：pytest 73 项（市场评分、特征仓、准入、决策复盘、新闻、模拟、敏感性、报告、降级等），本地确定性、零付费。
- 前端：TypeScript + Vite 构建校验。
- 演示数据：可复现的种子与公开数据刷新结构；测试库与演示库隔离，避免污染指标。
- 评测边界声明：演示结果不代表真实市场结论，不构成投资建议。

## 9. 数据边界

- 数据源：仅免费公开数据（PVGIS / World Bank Open Data / OWID / Open-Meteo / 公开 RSS-GDELT），无付费 API、无爬虫规避。
- 新闻只保存公开标题、RSS/API 摘要与受限短摘录，不做全文镜像。
- 每条结论可回溯到来源与 Evidence ID；页面与报告使用同一份 factor snapshot。
- 默认本地 SQLite 保存订阅/投递/审计；PostgreSQL/Redis 仅可选增强。

## 10. 非目标

- 不做自动投资决策，不给出投资建议
- 不做付费数据源或商业情报库
- 不自动准入/淘汰项目，不自动改变项目阶段
- 不做多租户 SaaS / 多人权限（当前为单人协作工具形态）

## 11. 成本测算（当前零成本运营）

全栈可本地 SQLite + Vite 运行，无云模型 API、无付费数据源；Ollama 为可选本地模型。进入增强模式后成本 = 本地推理电力 + 公开数据请求量，均在免费档覆盖内。
